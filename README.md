# Гостиница «Сугд» — Hotel SUGD

Одностраничный сайт гостиницы «Сугд» (Худжанд, Таджикистан).

- Один самодостаточный файл `index.html` — все фото встроены, внешних зависимостей нет (кроме Google Fonts).
- Адаптивная вёрстка, анимации, поддержка `prefers-reduced-motion`.
- Бронирование и вопросы — через WhatsApp.

## Публикация
`index.html` можно разместить на любом статическом хостинге (GitHub Pages, Netlify и т. п.).
